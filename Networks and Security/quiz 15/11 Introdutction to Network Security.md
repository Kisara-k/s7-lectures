## Answers

#### 1. What are the primary objectives of computer security?  
A) ✓ Protecting physical assets is a key objective of computer security.  
B) ✓ Ensuring data confidentiality and integrity is fundamental to security.  
C) ✗ Maximizing user privileges contradicts the principle of least privilege.  
D) ✓ Maintaining trust in the system is essential for dependable operation.  

**Correct:** A, B, D


#### 2. Which of the following are common sources of security threats?  
A) ✓ Associates like customers and contractors can pose risks as well.  
B) ✓ Insiders such as users and system administrators are major threat sources.  
C) ✗ Internal users are often responsible for incidents, so ignoring them is wrong.  
D) ✓ Outsiders including hackers and former employees can also be threats.  

**Correct:** A, B, D


#### 3. Why is network security considered more problematic than individual computer security?  
A) ✗ Networks have many avenues of attack, not fewer.  
B) ✗ Networks are heterogeneous, not homogeneous, which complicates security.  
C) ✓ Lack of central control increases security challenges.  
D) ✓ Networks are dispersed, making monitoring and control difficult.  

**Correct:** C, D


#### 4. Which statements about Internet security risks are true?  
A) ✓ Vulnerabilities are often exploited almost immediately after discovery.  
B) ✗ Internet security risks are generally greater than isolated networks.  
C) ✗ You have no control over all users on the Internet.  
D) ✓ Internet exposure means millions of unknown users can access your system.  

**Correct:** A, D


#### 5. In the context of electronic commerce security, which issues must be addressed?  
A) ✓ Authentication is critical to verify parties involved.  
B) ✗ Physical security of client hardware is less relevant to e-commerce security.  
C) ✓ Confidentiality and integrity protect transaction data.  
D) ✓ Accountability and non-repudiation ensure trust and legal enforceability.  

**Correct:** A, C, D


#### 6. What are effective methods to achieve system security?  
A) ✓ Principle of minimum privilege limits access to what is necessary.  
B) ✗ Allowing all users full access compromises security.  
C) ✗ Ignoring file and data control weakens security.  
D) ✓ Access control via identification and authentication is fundamental.  

**Correct:** A, D


#### 7. Which of the following are valid authentication methods?  
A) ✗ Something you guess is not a recognized authentication method.  
B) ✓ Something you are (fingerprint) is biometric authentication.  
C) ✓ Something you know (password) is a common method.  
D) ✓ Something you have (token) is a valid method.  

**Correct:** B, C, D


#### 8. Regarding bugs in a system, which statements are accurate?  
A) ✓ Some security holes are intentionally left as “features.”  
B) ✓ Using reliable, security-focused components reduces risk.  
C) ✓ All systems have bugs that can be exploited.  
D) ✗ More components usually increase complexity and bugs, not reduce them.  

**Correct:** A, B, C


#### 9. What are the challenges in securing client machines on a network?  
A) ✗ Clients are usually controlled by users, not administrators.  
B) ✓ Users often prefer features over security, increasing risk.  
C) ✓ Some OSs (e.g., Win 9x) lack strong security design.  
D) ✓ Some applications (e.g., MS Office) are not designed with security in mind.  

**Correct:** B, C, D


#### 10. Which statements about firewalls are true?  
A) ✗ Firewalls do not replace the need to secure individual machines.  
B) ✗ Configuring firewalls is complex and requires regular updates.  
C) ✓ Firewalls can deny unauthorized access both inbound and outbound.  
D) ✓ Firewalls separate secure networks from less secure ones.  

**Correct:** C, D


#### 11. What are the main functions of a firewall?  
A) ✓ Logging access attempts and raising alarms on suspicious activity is standard.  
B) ✓ Denying unauthorized access from outside to inside is a core function.  
C) ✗ Firewalls do not automatically fix vulnerabilities.  
D) ✓ Controlling access to authorized services is essential.  

**Correct:** A, B, D


#### 12. Which of the following describe public key encryption correctly?  
A) ✓ Privacy is ensured by encrypting with the recipient’s public key.  
B) ✓ Difficulty of breaking encryption depends on key length.  
C) ✗ Public keys cannot decrypt messages; only private keys can.  
D) ✓ Integrity can be verified by encrypting with the sender’s private key.  

**Correct:** A, B, D


#### 13. What security concerns are associated with web client software?  
A) ✓ Browsers have many features, each a potential security hole.  
B) ✓ Downloaded files may contain viruses or trojans.  
C) ✗ JavaScript and Java have security models, though not perfect.  
D) ✓ ActiveX controls have many known security problems.  

**Correct:** A, B, D


#### 14. Which statements about Secure Socket Layer (SSL) are correct?  
A) ✗ SSL does not secure data once it reaches the server or client storage.  
B) ✓ SSL protects data only during transmission, not at rest.  
C) ✓ SSL encrypts data transferred between browser and server.  
D) ✓ SSL identifies the server and optionally the user.  

**Correct:** B, C, D


#### 15. Why is it important to keep all machines up-to-date and have a recovery plan?  
A) ✓ Recovery plans enable quick restoration after breaches or failures.  
B) ✓ No system can be 100% safe, so updates reduce vulnerabilities.  
C) ✗ Updates are necessary even if a firewall is in place.
