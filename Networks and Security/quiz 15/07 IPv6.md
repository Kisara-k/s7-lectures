## Questions

## Answers

#### 1. Which of the following are design goals of IPv6?  
A) ✓ IPv6 aims to reduce the size of the global routing table.  
B) ✓ More address space is a primary design goal of IPv6.  
C) ✓ Encryption and authentication are built into IPv6 by design.  
D) ✗ Broadcast support is removed, replaced by multicast.  

**Correct:** A, B, C


#### 2. What are the consequences of the widespread use of NAT in IPv4 networks?  
A) ✗ NAT complicates network management and diagnosis rather than simplifying it.  
B) ✓ NAT causes loss of transparency in the Internet.  
C) ✗ NAT arose because of private address space, not eliminating it.  
D) ✓ NAT has led to a bifurcation of the Internet into application-rich and application-poor segments.  

**Correct:** B, D


#### 3. Which of the following statements about IPv6 address structure are true?  
A) ✓ CIDR subnetting is used in IPv6.  
B) ✓ IPv6 addresses are 128 bits long.  
C) ✗ The host part is usually based on MAC address or privacy extensions, not always random.  
D) ✓ Typically, 64 bits are used for network and 64 bits for host.  

**Correct:** A, B, D


#### 4. Which types of IPv6 addresses exist and what are their characteristics?  
A) ✗ Broadcast does not exist in IPv6.  
B) ✓ Anycast delivers packets to the nearest interface among a group.  
C) ✓ Multicast delivers packets to all interfaces with that address.  
D) ✓ Unicast delivers packets to a single interface.  

**Correct:** B, C, D


#### 5. Why does IPv6 not include broadcast addresses?  
A) ✗ Anycast does not replace broadcast; it serves a different purpose.  
B) ✗ Broadcast is not removed due to security concerns but design choice.  
C) ✓ All-zero and all-one addresses are legal in IPv6 because no broadcast exists.  
D) ✓ Broadcast functionality is replaced by multicast.  

**Correct:** C, D


#### 6. Which of the following are valid ways to shorten or represent IPv6 addresses?  
A) ✗ Only one "::" can be used in an address to avoid ambiguity.  
B) ✓ One contiguous all-zero group can be replaced by "::".  
C) ✓ Leading zeros in each 16-bit group may be omitted.  
D) ✗ Dotted decimal notation is only used for embedded IPv4 parts, not full IPv6.  

**Correct:** B, C


#### 7. Which of the following are true about IPv6 unicast address types?  
A) ✓ The unspecified address (::) is all zeros and used during initialization.  
B) ✗ Link-local addresses (FE80::/10) are not routable beyond the local subnet.  
C) ✓ Site-local addresses (FEC0::/10) are for isolated networks but considered deprecated/endangered.  
D) ✓ The loopback address (::1) is equivalent to IPv4 127.0.0.1.  

**Correct:** A, C, D


#### 8. What is the purpose of IPv4-mapped IPv6 addresses?  
A) ✗ IPv4-mapped addresses (::FFFF:a.b.c.d) are used by dual-stack machines to communicate over IPv4, not IPv6 over IPv4.  
B) ✓ They represent IPv4 addresses within an IPv6 format.  
C) ✗ They do not replace IPv4 addresses entirely; they facilitate interoperability.  
D) ✓ Dual-stack machines use these to communicate using IPv4 over IPv6 stacks.  

**Correct:** B, D


#### 9. Regarding IPv6 address allocation, which statements are correct?  
A) ✗ Each interface usually has multiple IPv6 addresses, not just one.  
B) ✓ Each network is generally assigned a /64 prefix.  
C) ✓ End sites typically receive /48 allocations from Regional Internet Registries.  
D) ✗ /32 prefixes are allocated to ISPs or large organizations, not individual hosts.  

**Correct:** B, C


#### 10. How is the 64-bit interface identifier in IPv6 typically generated from a MAC address?  
A) ✗ The MAC address is not appended directly without modification.  
B) ✓ Privacy addresses use random 64-bit numbers, but standard interface IDs come from MAC.  
C) ✓ The 7th bit of the first octet is inverted (universal/local bit).  
D) ✓ "fffe" is inserted in the middle of the MAC address to form EUI-64.  

**Correct:** B, C, D


#### 11. Which of the following are true about IPv6 autoconfiguration?  
A) ✓ Hosts send ICMP Router Solicitation messages (type 133) to FF02::2 to discover routers.  
B) ✓ Hosts assign themselves link-local addresses using FE80::/10 prefix.  
C) ✓ If no router responds, the host uses only its link-local address.  
D) ✗ Autoconfiguration does not provide DNS server addresses automatically.  

**Correct:** A, B, C


#### 12. What are some challenges or problems associated with multiple IPv6 addresses on a single interface?  
A) ✗ IPv6 supports multiple addresses per interface by design.  
B) ✓ Hosts or apps may choose addresses conflicting with routing policies.  
C) ✓ Incorrect address choice can break connectivity.  
D) ✗ Address selection rules are complex and controversial, not simple or universally agreed.  

**Correct:** B, C


#### 13. Which fields are new or changed in the IPv6 header compared to IPv4?  
A) ✗ Fragment Offset field is removed; fragmentation handled differently.  
B) ✓ Hop Limit replaces Time-to-Live.  
C) ✓ Header Checksum is removed in IPv6.  
D) ✓ Flow Label (20 bits) is a new field in IPv6.  

**Correct:** B, C, D


#### 14. What are the purposes of IPv6 extension headers?  
A) ✗ They do not increase fixed header size; base header is fixed length.  
B) ✓ They replace the variable-length options field in IPv4 headers.  
C) ✓ Provide additional functionality like routing, fragmentation, and security.  
D) ✗ Routers are intended to do minimal processing, not complex inspection.  

**Correct:** B, C


#### 15. Which of the following statements about IPv6 transition mechanisms are correct?  
A) ✓ IPv6 packets can be tunneled inside IPv4 packets to traverse IPv4 networks.  
B) ✓ AAAA records map hostnames to IPv6 addresses, extending A records.  
C) ✓ DNS faces namespace fragmentation challenges between IPv4 and IPv6.  
D) ✗ Application Layer Gateways (ALGs) are needed when applications embed IP addresses.  

**Correct:** A, B, C
