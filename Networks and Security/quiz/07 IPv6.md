## Answers

#### 1. Which of the following are design goals of IPv6?  
A) ✓ More address space is a primary design goal of IPv6.  
B) ✓ IPv6 aims to reduce the size of the global routing table.  
C) ✓ Encryption and authentication are built into IPv6 by design.  
D) ✗ Broadcast support is removed, replaced by multicast.  

**Correct:** A, B, C


#### 2. What are the consequences of the widespread use of NAT in IPv4 networks?  
A) ✓ NAT causes loss of transparency in the Internet.  
B) ✓ NAT has led to a bifurcation of the Internet into application-rich and application-poor segments.  
C) ✗ NAT complicates network management and diagnosis rather than simplifying it.  
D) ✗ NAT arose because of private address space, not eliminating it.  

**Correct:** A, B


#### 3. Which of the following statements about IPv6 address structure are true?  
A) ✓ IPv6 addresses are 128 bits long.  
B) ✓ Typically, 64 bits are used for network and 64 bits for host.  
C) ✗ The host part is usually based on MAC address or privacy extensions, not always random.  
D) ✓ CIDR subnetting is used in IPv6.  

**Correct:** A, B, D


#### 4. Which types of IPv6 addresses exist and what are their characteristics?  
A) ✓ Unicast delivers packets to a single interface.  
B) ✓ Multicast delivers packets to all interfaces with that address.  
C) ✓ Anycast delivers packets to the nearest interface among a group.  
D) ✗ Broadcast does not exist in IPv6.  

**Correct:** A, B, C


#### 5. Why does IPv6 not include broadcast addresses?  
A) ✓ Broadcast functionality is replaced by multicast.  
B) ✗ Broadcast is not removed due to security concerns but design choice.  
C) ✓ All-zero and all-one addresses are legal in IPv6 because no broadcast exists.  
D) ✗ Anycast does not replace broadcast; it serves a different purpose.  

**Correct:** A, C


#### 6. Which of the following are valid ways to shorten or represent IPv6 addresses?  
A) ✓ Leading zeros in each 16-bit group may be omitted.  
B) ✓ One contiguous all-zero group can be replaced by "::".  
C) ✗ Dotted decimal notation is only used for embedded IPv4 parts, not full IPv6.  
D) ✗ Only one "::" can be used in an address to avoid ambiguity.  

**Correct:** A, B


#### 7. Which of the following are true about IPv6 unicast address types?  
A) ✓ The unspecified address (::) is all zeros and used during initialization.  
B) ✓ The loopback address (::1) is equivalent to IPv4 127.0.0.1.  
C) ✗ Link-local addresses (FE80::/10) are not routable beyond the local subnet.  
D) ✓ Site-local addresses (FEC0::/10) are for isolated networks but considered deprecated/endangered.  

**Correct:** A, B, D


#### 8. What is the purpose of IPv4-mapped IPv6 addresses?  
A) ✗ IPv4-mapped addresses (::FFFF:a.b.c.d) are used by dual-stack machines to communicate over IPv4, not IPv6 over IPv4.  
B) ✓ They represent IPv4 addresses within an IPv6 format.  
C) ✓ Dual-stack machines use these to communicate using IPv4 over IPv6 stacks.  
D) ✗ They do not replace IPv4 addresses entirely; they facilitate interoperability.  

**Correct:** B, C


#### 9. Regarding IPv6 address allocation, which statements are correct?  
A) ✗ Each interface usually has multiple IPv6 addresses, not just one.  
B) ✓ Each network is generally assigned a /64 prefix.  
C) ✓ End sites typically receive /48 allocations from Regional Internet Registries.  
D) ✗ /32 prefixes are allocated to ISPs or large organizations, not individual hosts.  

**Correct:** B, C


#### 10. How is the 64-bit interface identifier in IPv6 typically generated from a MAC address?  
A) ✓ "fffe" is inserted in the middle of the MAC address to form EUI-64.  
B) ✓ The 7th bit of the first octet is inverted (universal/local bit).  
C) ✗ The MAC address is not appended directly without modification.  
D) ✓ Privacy addresses use random 64-bit numbers, but standard interface IDs come from MAC.  

**Correct:** A, B, D


#### 11. Which of the following are true about IPv6 autoconfiguration?  
A) ✓ Hosts assign themselves link-local addresses using FE80::/10 prefix.  
B) ✓ Hosts send ICMP Router Solicitation messages (type 133) to FF02::2 to discover routers.  
C) ✗ Autoconfiguration does not provide DNS server addresses automatically.  
D) ✓ If no router responds, the host uses only its link-local address.  

**Correct:** A, B, D


#### 12. What are some challenges or problems associated with multiple IPv6 addresses on a single interface?  
A) ✓ Hosts or apps may choose addresses conflicting with routing policies.  
B) ✗ Address selection rules are complex and controversial, not simple or universally agreed.  
C) ✓ Incorrect address choice can break connectivity.  
D) ✗ IPv6 supports multiple addresses per interface by design.  

**Correct:** A, C


#### 13. Which fields are new or changed in the IPv6 header compared to IPv4?  
A) ✓ Flow Label (20 bits) is a new field in IPv6.  
B) ✓ Header Checksum is removed in IPv6.  
C) ✓ Hop Limit replaces Time-to-Live.  
D) ✗ Fragment Offset field is removed; fragmentation handled differently.  

**Correct:** A, B, C


#### 14. What are the purposes of IPv6 extension headers?  
A) ✓ They replace the variable-length options field in IPv4 headers.  
B) ✓ Provide additional functionality like routing, fragmentation, and security.  
C) ✗ They do not increase fixed header size; base header is fixed length.  
D) ✗ Routers are intended to do minimal processing, not complex inspection.  

**Correct:** A, B


#### 15. Which of the following statements about IPv6 transition mechanisms are correct?  
A) ✓ IPv6 packets can be tunneled inside IPv4 packets to traverse IPv4 networks.  
B) ✗ Application Layer Gateways (ALGs) are needed when applications embed IP addresses.  
C) ✓ DNS faces namespace fragmentation challenges between IPv4 and IPv6.  
D) ✓ AAAA records map hostnames to IPv6 addresses, extending A records.  

**Correct:** A, C, D
