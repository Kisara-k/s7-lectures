## 14 Network Design

## Questions

#### 1. Which of the following are important considerations when aligning network design with business needs?

B) Return on investment  
C) Cost of network infrastructure vs. added value  
D) Number of network protocols supported  

#### 2. When planning for future growth in network design, which factors should be taken into account?  
A) Expected expansion of applications, services, and servers  
B) Adaptation of new technologies  
C) Physical security of network devices only  
D) Use of third-party/public providers for island-wide coverage  

#### 3. Regarding existing infrastructure in network design, which statements are true?  
A) All existing equipment should be discarded to avoid legacy issues  
B) Capital expenditure considerations may justify reusing existing infrastructure  
C) Locations of buildings and physical accessibility influence network design  
D) Multi-mode fiber optic backbones are best placed in a central location for star topology  

#### 4. What are key factors to consider when deciding Internet and intranet requirements for branches?  
A) Whether branches should have separate Internet connections or route through head-office  
B) Balancing controllability versus freedom and confidentiality versus openness  
C) Ensuring all branches have identical bandwidth allocations regardless of usage  
D) Dependency on a single Internet provider and its impact on reliability  

#### 5. In balancing security versus accessibility requirements, which policies and considerations are essential?  
A) Organizational and IT security policies  
B) Accessibility for mobile employees  
C) Single sign-on versus distributed authentication  
D) Allowing unrestricted access to all servers for ease of use  

#### 6. When selecting an appropriate network architecture, which principles should guide the design?  
A) Avoid overly complex architectures and estimate current needs accurately  
B) Assume equipment will remain current and relevant for at least ten years

#### 7. Which design strategies are valid approaches to network design?  
A) Function (application) based design  
B) Security based design  
C) Topology (technology/protocol) based design  
D) Color-coded cable design  

#### 8. In function (application) based design, what should be considered?  
A) Different types of business applications and data for various organizations  
B) Designing networks solely based on the fastest available technology  
C) Aligning network design with business drivers, IT infrastructure, and disaster recovery  
D) Ignoring server and storage requirements  

#### 9. Which of the following are critical elements in security based design?

#### 12. Regarding traffic based design, which considerations are important?

#### 13. Which statements about network infrastructure longevity and upgrades are accurate?

B) Structured cabling can last longer and ease future enhancements

#### 14. In security based design, what is the role of access policies?  
A) Imposing limited access through proxies and NAT  
B) Granting privileged access using VPNs and role-based authentication  
C) Allowing all employees unrestricted access to all network resources  
D) Defining policies for office setups, branches, and third-party access  

#### 15. Which of the following are true about Internet and intranet service considerations?  
A) Public services and internal services require different access controls  
B) Controllability and policing are irrelevant in intranet design  
C) Dependency on a single provider can affect reliability and availability  
D) Branches should always have independent Internet connections regardless of cost or control needs

## Answers

#### 1. Which of the following are important considerations when aligning network design with business needs?  
A) ✓ Competitive advantage — Network design should support gaining or maintaining competitive advantage.  
B) ✓ Return on investment — Cost-effectiveness and ROI are key business considerations.  
C) ✓ Cost of network infrastructure vs. added value — Balancing cost against business value is essential.  
D) ✗ Number of network protocols supported — This is a technical detail, not a primary business alignment factor.  

**Correct:** A, B, C


#### 2. When planning for future growth in network design, which factors should be taken into account?  
A) ✓ Expected expansion of applications, services, and servers — Growth in these areas drives network scaling.  
B) ✓ Adaptation of new technologies — Networks must evolve with technology changes.  
C) ✗ Physical security of network devices only — Important but too narrow; future growth involves more than security.  
D) ✓ Use of third-party/public providers for island-wide coverage — Outsourcing and coverage expansion are growth considerations.  

**Correct:** A, B, D


#### 3. Regarding existing infrastructure in network design, which statements are true?  
A) ✗ All existing equipment should be discarded to avoid legacy issues — Throwing away everything is not justified.  
B) ✓ Capital expenditure considerations may justify reusing existing infrastructure — Cost savings encourage reuse.  
C) ✓ Locations of buildings and physical accessibility influence network design — Physical factors affect infrastructure placement.  
D) ✓ Multi-mode fiber optic backbones are best placed in a central location for star topology — Centralized core switch placement is recommended.  

**Correct:** B, C, D


#### 4. What are key factors to consider when deciding Internet and intranet requirements for branches?  
A) ✓ Whether branches should have separate Internet connections or route through head-office — Affects control and cost.  
B) ✓ Balancing controllability versus freedom and confidentiality versus openness — Important trade-offs in design.  
C) ✗ Ensuring all branches have identical bandwidth allocations regardless of usage — Not practical or efficient.  
D) ✓ Dependency on a single Internet provider and its impact on reliability — Single points of failure affect availability.  

**Correct:** A, B, D


#### 5. In balancing security versus accessibility requirements, which policies and considerations are essential?  
A) ✓ Organizational and IT security policies — Define access and security rules.  
B) ✓ Accessibility for mobile employees — Must balance security with mobility needs.  
C) ✓ Single sign-on versus distributed authentication — Important for managing access control.  
D) ✗ Allowing unrestricted access to all servers for ease of use — Contradicts security principles.  

**Correct:** A, B, C


#### 6. When selecting an appropriate network architecture, which principles should guide the design?  
A) ✓ Avoid overly complex architectures and estimate current needs accurately — Practical and cost-effective approach.  
B) ✗ Assume equipment will remain current and relevant for at least ten years — Equipment typically becomes outdated faster.  
C) ✓ Structured cabling facilitates easier management and cost-effective enhancements — Structured cabling is a long-term asset.  
D) ✗ Focus only on server workloads, ignoring traffic loads and application types — Traffic and applications are critical factors.  

**Correct:** A, C


#### 7. Which design strategies are valid approaches to network design?  
A) ✓ Function (application) based design — Aligns network with business applications.  
B) ✓ Security based design — Addresses protection needs.  
C) ✓ Topology (technology/protocol) based design — Considers physical and protocol aspects.  
D) ✗ Color-coded cable design — Not a recognized design strategy, just a cabling practice.  

**Correct:** A, B, C


#### 8. In function (application) based design, what should be considered?  
A) ✓ Different types of business applications and data for various organizations — Core to this design approach.  
B) ✗ Designing networks solely based on the fastest available technology — Ignores business needs and data types.  
C) ✓ Aligning network design with business drivers, IT infrastructure, and disaster recovery — Ensures business-IT alignment.  
D) ✗ Ignoring server and storage requirements — These are essential components of application support.  

**Correct:** A, C


#### 9. Which of the following are critical elements in security based design?  
A) ✓ Physical and network-based threats — Both must be addressed.  
B) ✓ Use of proxies and NAT for limited access and IP depletion mitigation — Common security and network management tools.  
C) ✓ Critical node protection such as server farms and VLANs — Protects key network segments.  
D) ✗ Allowing open access to all network segments to simplify management — Contradicts security principles.  

**Correct:** A, B, C


#### 10. What are some advanced security mechanisms used in network design?  
A) ✓ Firewalls, IDSs, and IDPs — Essential for threat detection and prevention.  
B) ✓ Multi-tier architectures for critical application communications — Enhances security by isolation.  
C) ✓ Use of SSL and cryptography for application-level security — Protects data in transit.  
D) ✗ Disabling VLANs to reduce complexity — VLANs improve security and segmentation, disabling them reduces security.  

**Correct:** A, B, C


#### 11. When considering topology (technology/protocol) based design, which factors are relevant?  
A) ✓ Differences in LAN, WLAN, and WAN technologies and speeds — Affects design choices.  
B) ✓ Budgetary and environmental constraints — Real-world constraints impact design.  
C) ✓ Use of VPNs and tunnels for extended networks — Important for secure WAN extensions.  
D) ✗ Ignoring security concerns over WANs — Security is critical over WANs.  

**Correct:** A, B, C


#### 12. Regarding traffic based design, which considerations are important?  
A) ✓ Queuing and priority traffic management — Manages congestion and QoS.  
B) ✓ Whether applications can tolerate delays — Determines acceptable latency.  
C) ✓ Load balancing and switching at wire-speed — Ensures performance and reliability.  
D) ✗ Designing networks without redundant paths to save costs — Redundancy is key for reliability.  

**Correct:** A, B, C


#### 13. Which statements about network infrastructure longevity and upgrades are accurate?  
A) ✓ Most network equipment becomes outdated within three years — Typical technology lifecycle.  
B) ✓ Structured cabling can last longer and ease future enhancements — Cabling is a long-term asset.  
C) ✗ Throwing away existing infrastructure is always justified to avoid legacy issues — Not always cost-effective or necessary.  
D) ✓ Reusing infrastructure at different network levels can be beneficial if restructured — Can save costs and resources.  

**Correct:** A, B, D


#### 14. In security based design, what is the role of access policies?  
A) ✓ Imposing limited access through proxies and NAT — Controls and restricts access.  
B) ✓ Granting privileged access using VPNs and role-based authentication — Ensures only authorized users access sensitive resources.  
C) ✗ Allowing all employees unrestricted access to all network resources — Violates security principles.  
D) ✓ Defining policies for office setups, branches, and third-party access — Important for consistent security enforcement.  

**Correct:** A, B, D


#### 15. Which of the following are true about Internet and intranet service considerations?  
A) ✓ Public services and internal services require different access controls — Different security and accessibility needs.  
B) ✗ Controllability and policing are irrelevant in intranet design — They are important for security and management.  
C) ✓ Dependency on a single provider can affect reliability and availability — Single points of failure are risky.  
D) ✗ Branches should always have independent Internet connections regardless of cost or control needs — This depends on design goals and trade-offs.  

**Correct:** A, C
