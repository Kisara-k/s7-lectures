## Answers

#### 1. What are the primary objectives of computer security?  
A) ✓ Protecting physical assets is a key objective of computer security.  
B) ✓ Ensuring data confidentiality and integrity is fundamental to security.  
C) ✗ Maximizing user privileges contradicts the principle of least privilege.  
D) ✓ Maintaining trust in the system is essential for dependable operation.  

**Correct:** A, B, D


#### 2. Which of the following are common sources of security threats?  
A) ✓ Insiders such as users and system administrators are major threat sources.  
B) ✓ Outsiders including hackers and former employees can also be threats.  
C) ✗ Internal users are often responsible for incidents, so ignoring them is wrong.  
D) ✓ Associates like customers and contractors can pose risks as well.  

**Correct:** A, B, D


#### 3. Why is network security considered more problematic than individual computer security?  
A) ✓ Networks are dispersed, making monitoring and control difficult.  
B) ✗ Networks are heterogeneous, not homogeneous, which complicates security.  
C) ✓ Lack of central control increases security challenges.  
D) ✗ Networks have many avenues of attack, not fewer.  

**Correct:** A, C


#### 4. Which statements about Internet security risks are true?  
A) ✓ Internet exposure means millions of unknown users can access your system.  
B) ✓ Vulnerabilities are often exploited almost immediately after discovery.  
C) ✗ You have no control over all users on the Internet.  
D) ✗ Internet security risks are generally greater than isolated networks.  

**Correct:** A, B


#### 5. In the context of electronic commerce security, which issues must be addressed?  
A) ✓ Authentication is critical to verify parties involved.  
B) ✓ Confidentiality and integrity protect transaction data.  
C) ✓ Accountability and non-repudiation ensure trust and legal enforceability.  
D) ✗ Physical security of client hardware is less relevant to e-commerce security.  

**Correct:** A, B, C


#### 6. What are effective methods to achieve system security?  
A) ✓ Access control via identification and authentication is fundamental.  
B) ✗ Allowing all users full access compromises security.  
C) ✓ Principle of minimum privilege limits access to what is necessary.  
D) ✗ Ignoring file and data control weakens security.  

**Correct:** A, C


#### 7. Which of the following are valid authentication methods?  
A) ✓ Something you have (token) is a valid method.  
B) ✓ Something you know (password) is a common method.  
C) ✓ Something you are (fingerprint) is biometric authentication.  
D) ✗ Something you guess is not a recognized authentication method.  

**Correct:** A, B, C


#### 8. Regarding bugs in a system, which statements are accurate?  
A) ✓ All systems have bugs that can be exploited.  
B) ✓ Some security holes are intentionally left as “features.”  
C) ✗ More components usually increase complexity and bugs, not reduce them.  
D) ✓ Using reliable, security-focused components reduces risk.  

**Correct:** A, B, D


#### 9. What are the challenges in securing client machines on a network?  
A) ✓ Some OSs (e.g., Win 9x) lack strong security design.  
B) ✓ Users often prefer features over security, increasing risk.

**Correct:** A, B, D


#### 10. Which statements about firewalls are true?  
A) ✓ Firewalls separate secure networks from less secure ones.  
B) ✗ Configuring firewalls is complex and requires regular updates.  
C) ✓ Firewalls can deny unauthorized access both inbound and outbound.  
D) ✗ Firewalls do not replace the need to secure individual machines.  

**Correct:** A, C


#### 11. What are the main functions of a firewall?  
A) ✓ Denying unauthorized access from outside to inside is a core function.  
B) ✓ Controlling access to authorized services is essential.  
C) ✓ Logging access attempts and raising alarms on suspicious activity is standard.

**Correct:** A, B, C


#### 12. Which of the following describe public key encryption correctly?

#### 13. What security concerns are associated with web client software?  
A) ✓ Browsers have many features, each a potential security hole.
