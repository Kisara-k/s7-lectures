## 10 Other Networking Protocols

## Questions

#### 1. Which of the following statements correctly describe Bluetooth technology?

C) Bluetooth piconets allow direct communication between slave devices without involving the master.  
D) Bluetooth protocol stack includes layers such as LMP, L2CAP, SDP, and Baseband for managing connections and services.  

#### 2. When designing a simple protocol to control multiple lights in a room, which of the following considerations are relevant regarding TCP and UDP usage?

B) UDP is preferable for low-latency control commands because it has less overhead and no connection setup.  
C) Both TCP and UDP require IP and Ethernet layers, which may be overkill for simple light control applications.  
D) TCP is always better than UDP for controlling lights because it guarantees delivery and order.

D) NFC data rates can reach up to 2.1 Mbps, comparable to Bluetooth Classic.

C) Cluster tree topology eliminates the risk of a single point of failure at the root node.  
D) ZigBee devices can be either Full Functional Devices (FFD) or Reduced Functional Devices (RFD), with FFDs capable of acting as coordinators.

## Answers

#### 1. Which of the following statements correctly describe Bluetooth technology?  
A) ✓ Bluetooth operates in the 2.4 - 2.48 GHz ISM band with a typical range of about 10 meters.  
B) ✗ Bluetooth Low Energy (BLE) is designed for low power, not high data rate like Wi-Fi.  
C) ✗ Bluetooth piconets do not allow direct slave-to-slave communication; all communication goes through the master.  
D) ✓ Bluetooth protocol stack includes LMP, L2CAP, SDP, and Baseband layers for managing connections and services.  

**Correct:** A, D


#### 2. When designing a simple protocol to control multiple lights in a room, which of the following considerations are relevant regarding TCP and UDP usage?  
A) ✓ TCP has higher overhead due to connection setup and reliability features.  
B) ✓ UDP is preferable for low-latency commands because it has less overhead and no connection setup.  
C) ✓ Both TCP and UDP require IP and Ethernet layers, which may be overkill for simple control applications.  
D) ✗ TCP is not always better; for simple control, UDP’s lightweight nature can be more suitable.  

**Correct:** A, B, C


#### 3. Which of the following are true about Near Field Communication (NFC)?  
A) ✓ NFC operates at 13.56 MHz with a range of about 10 cm.  
B) ✗ NFC does not require pairing like Bluetooth; it has no search and pair procedure.  
C) ✓ NFC supports active and passive modes; passive mode uses the field generated by the active device.  
D) ✗ NFC data rates max out at 424 Kbps, much lower than Bluetooth Classic’s 2.1 Mbps.  

**Correct:** A, C


#### 4. Regarding ZigBee technology and its network topologies, which statements are accurate?  
A) ✓ Star topology is easy to synchronize but limited in scale.  
B) ✓ Mesh topology offers robust multi-hop communication but requires costly route discovery and routing table maintenance.  
C) ✗ Cluster tree topology does not eliminate single point of failure; the root can still be a single point of failure.  
D) ✓ ZigBee devices can be FFDs or RFDs; FFDs can act as coordinators.  

**Correct:** A, B, D


#### 5. Which of the following correctly describe the ZigBee protocol stack and device types?  
A) ✓ ZigBee builds on IEEE 802.15.4, which defines physical and MAC layers for low-rate WPANs.  
B) ✗ RFDs communicate only with FFDs, not directly with other RFDs.  
C) ✓ ZigBee profiles define common languages and services to ensure device interoperability.  
D) ✓ ZigBee network layer uses 16-bit addresses and route discovery via RREQ and RREP packets.  

**Correct:** A, C, D


#### 6. Comparing Bluetooth, ZigBee, NFC, and Low Power Wi-Fi, which of the following statements are correct?  
A) ✓ ZigBee and Bluetooth offer longer battery life (months/years) compared to NFC (hours).  
B) ✓ Bluetooth uses GFSK modulation; ZigBee uses BPSK and QPSK modulation schemes.  
C) ✓ NFC supports higher data rates than ZigBee (424 Kbps vs. 250 Kbps) but lower than Low Power Wi-Fi (54 Mbps).  
D) ✗ Low Power Wi-Fi is more complex and consumes more power than ZigBee and Bluetooth.  

**Correct:** A, B, C


#### 7. Which of the following are valid reasons why TCP/IP might be considered overkill or unsuitable for certain network applications?  
A) ✓ TCP/IP has a high footprint, making it unsuitable for low-power or resource-constrained devices.  
B) ✗ Not all networks require IP addressing; some use custom protocols without IP.  
C) ✓ Custom protocols like Bluetooth, ZigBee, or NFC can be more efficient for specific use cases.  
D) ✗ TCP/IP supports multi-hop routing (e.g., via IP routing); lack of multi-hop is not a limitation.  

**Correct:** A, C


#### 8. In the context of Bluetooth piconets and scatternets, which statements are true?  
A) ✓ A Bluetooth piconet has one master and up to seven active slaves; no direct slave-to-slave communication.  
B) ✓ Scatternets connect multiple piconets, allowing devices to participate in more than one piconet.  
C) ✗ Slaves cannot communicate directly with each other within a piconet; communication must go through the master.  
D) ✓ Up to 255 parked slaves can be in a piconet, which can be activated when needed.  

**Correct:** A, B, D
