## Questions

## Answers

#### 1. Which of the following are design goals of IPv6?  
A) ✓ Larger address space than IPv4 — IPv6 was designed to provide a vastly larger address space (128 bits vs. 32 bits).  
B) ✓ Built-in encryption and authentication — IPv6 includes IPsec support as a mandatory part of the protocol.  
C) ✗ Maintaining broadcast functionality from IPv4 — IPv6 removes broadcast and replaces it with multicast.  
D) ✓ Smaller global routing tables — One goal is to reduce routing table size through aggregation and hierarchical addressing.  

**Correct:** A, B, D


#### 2. Regarding IPv6 address types, which statements are true?  
A) ✗ IPv6 supports unicast, multicast, anycast, and broadcast addresses — IPv6 does not have broadcast addresses; multicast replaces broadcast.  
B) ✓ Broadcast addresses do not exist in IPv6; multicast replaces broadcast functionality — This is a fundamental change in IPv6.  
C) ✓ Anycast addresses deliver packets to the nearest interface among a group — Anycast is defined to deliver to the nearest interface with that address.  
D) ✗ IPv6 unicast addresses refer to nodes, not interfaces — IPv6 unicast addresses are assigned to interfaces, not nodes.  

**Correct:** B, C


#### 3. Which of the following correctly describe IPv6 interface identifiers?  
A) ✓ They are 64 bits long and often derived from the MAC address using EUI-64 format — Interface IDs are 64 bits and commonly formed from MAC addresses.  
B) ✓ The universal/local bit is inverted in the first octet when forming the interface ID — This is part of the EUI-64 conversion rules.  
C) ✗ Privacy addresses are fixed and based on the MAC address to ensure uniqueness — Privacy addresses are random and change over time to protect privacy.  
D) ✓ The same interface identifier can be used on multiple interfaces of a single node — The same interface ID may appear on multiple interfaces of one node.  

**Correct:** A, B, D


#### 4. What are the implications of using NAT in IPv4 that IPv6 aims to address?  
A) ✓ NAT causes loss of transparency in the network — NAT hides end-to-end addressing, reducing transparency.  
B) ✓ NAT leads to bifurcation of the Internet into application-rich and application-poor segments — NAT complicates application behavior and network management.  
C) ✗ NAT increases the size of the global routing table — NAT reduces the need for global addresses, but routing table size is more related to address aggregation.  
D) ✗ NAT eliminates the need for private address spaces — NAT was developed because of private address spaces, not to eliminate them.  

**Correct:** A, B


#### 5. Which of the following statements about IPv6 autoconfiguration are correct?  
A) ✓ Hosts assign themselves link-local addresses using the FE80::/10 prefix and EUI-64 interface IDs — This is the standard autoconfiguration process.  
B) ✓ Router advertisements are sent in response to ICMP Router Solicitation messages from hosts — Routers respond to solicitations with advertisements.  
C) ✗ Autoconfiguration automatically provides DNS and time server information to hosts — Basic autoconfiguration does not provide DNS or time server info.  
D) ✓ If no router responds, the host continues to use only its link-local address — Without router response, the host uses only link-local for communication.  

**Correct:** A, B, D


#### 6. Concerning IPv6 packet headers, which statements are accurate?  
A) ✓ The IPv6 header includes a fixed-length 20-bit Flow Label field for special handling of packets — The Flow Label is a new 20-bit field for QoS and flow identification.  
B) ✗ IPv6 headers include a checksum field to ensure header integrity — IPv6 removes the header checksum, relying on upper-layer checksums.  
C) ✓ Fragmentation is handled only by the source host, not by routers along the path — Routers do not fragment; hosts must perform fragmentation.  
D) ✓ Extension headers replace the variable-length options field found in IPv4 headers — IPv6 uses extension headers instead of IPv4 options.  

**Correct:** A, C, D


#### 7. Which challenges are associated with multiple IPv6 addresses on a single interface?  
A) ✓ Hosts or applications may select an inappropriate global address, conflicting with routing policies — Address selection can override policy and cause connectivity issues.  
B) ✗ Address selection rules are simple and universally agreed upon — The rules are complex and controversial.  
C) ✓ IPv6 assumes multiple addresses per interface, including link-local, global, privacy, and site-local — Multiple addresses per interface is a core IPv6 assumption.  
D) ✗ Multi-homed addresses eliminate all connectivity issues related to address selection — Multi-homing introduces complexity and does not solve all issues.  

**Correct:** A, C


#### 8. Regarding IPv6 transition mechanisms and DNS, which statements are true?  
A) ✓ IPv6 uses AAAA records to map hostnames to 128-bit IPv6 addresses — AAAA records are the IPv6 equivalent of A records.  
B) ✗ IPv4-only hosts can directly resolve IPv6-only DNS names without special mechanisms — IPv4-only hosts cannot resolve IPv6-only names without dual-stack or proxies.  
C) ✓ Tunnels encapsulate IPv6 packets inside IPv4 packets to traverse IPv4 networks — Tunneling is a common transition mechanism.  
D) ✗ Application Layer Gateways (ALGs) are unnecessary in IPv6 because IP addresses are never embedded in application data — ALGs are still needed when applications embed IP addresses.  

**Correct:** A, C
