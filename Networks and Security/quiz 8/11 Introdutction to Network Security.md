## 11 Introdutction to Network Security

## Questions

#### 1. Which of the following are considered primary objectives of computer security?  
A) Protecting physical assets  
B) Protecting data and software  
C) Ensuring system usability by allowing all access  
D) Maintaining trust in the system  

#### 2. Why is network security more challenging than securing a single computer system?  
A) There are multiple avenues of attack due to lack of central control  
B) All nodes in a network are always visible and centrally controlled  
C) Networks are dispersed and may include many heterogeneous components  
D) Network security only involves securing hardware, not software  

#### 3. Which of the following statements about authentication methods are true?  
A) Authentication always guarantees complete system security  
B) Authentication can be based on something you know, such as a password  
C) Biometrics like fingerprints are examples of something you have  
D) Tokens are an example of something you have for authentication  

#### 4. Regarding encryption in data transfer security, which statements are correct?  
A) Dual key encryption involves each user having a public and private key pair  
B) Encryption ensures data confidentiality, integrity, and authentication during transmission  
C) Single-key encryption uses the same key for both encryption and decryption  
D) Public key encryption uses a private key to encrypt and a public key to decrypt for privacy  

#### 5. What are the main functions of a firewall in network security?  
A) Deny unauthorized access from outside to inside the network  
B) Allow unrestricted access to all services to improve usability  
C) Log access attempts and raise alarms on suspicious activity  
D) Control access to authorized services within the network  

#### 6. Which of the following are common security problems associated with web clients?  
A) ActiveX controls can introduce many security vulnerabilities  
B) JavaScript and Java have no security models and thus pose no risk  
C) Downloaded files may contain viruses or trojan horses  
D) Cookies can be used to track user behavior across websites  

#### 7. Why is it important to apply the principle of minimum privilege in user access control?  
A) To ensure that administrators have the same privileges as normal users  
B) To give users all privileges so they can perform any task without restrictions  
C) To limit users to only the privileges necessary to perform their work  
D) To reduce the risk of accidental or intentional misuse of system resources  

#### 8. Which of the following statements about securing servers and clients are true?  
A) Using a secure operating system and keeping it updated helps maintain server security  
B) Educating users is unnecessary if the client management system is in place  
C) Client security is less important because clients do not connect to networks  
D) Disabling unneeded features on servers reduces the attack surface

## Answers

#### 1. Which of the following are considered primary objectives of computer security?  
A) ✓ Protecting physical assets is a key objective of computer security.  
B) ✓ Protecting data and software is a fundamental security goal.  
C) ✗ Allowing all access compromises security and is not an objective.  
D) ✓ Maintaining trust in the system is essential for security.  

**Correct:** A, B, D


#### 2. Why is network security more challenging than securing a single computer system?  
A) ✓ Multiple attack avenues and lack of central control complicate network security.  
B) ✗ Not all nodes are visible or centrally controlled, making security harder.  
C) ✓ Networks are dispersed and include many heterogeneous components, increasing complexity.  
D) ✗ Network security involves both hardware and software, not just hardware.  

**Correct:** A, C


#### 3. Which of the following statements about authentication methods are true?  
A) ✗ Authentication helps verify identity but does not guarantee complete security.  
B) ✓ Passwords are something you know, a common authentication method.  
C) ✗ Fingerprints are something you are (biometrics), not something you have.  
D) ✓ Tokens are physical objects you have for authentication.  

**Correct:** B, D


#### 4. Regarding encryption in data transfer security, which statements are correct?  
A) ✓ Dual (public) key encryption involves each user having a public/private key pair.  
B) ✓ Encryption supports confidentiality, integrity, and authentication during transmission.  
C) ✓ Single-key (symmetric) encryption uses the same key for encryption and decryption.  
D) ✗ For privacy, public key encryption encrypts with the recipient’s public key and decrypts with their private key, not the other way around.  

**Correct:** A, B, C


#### 5. What are the main functions of a firewall in network security?  
A) ✓ Firewalls deny unauthorized access from outside to inside the network.  
B) ✗ Allowing unrestricted access contradicts the purpose of a firewall.  
C) ✓ Firewalls log access attempts and raise alarms on suspicious activity.  
D) ✓ Firewalls control access to authorized services within the network.  

**Correct:** A, C, D


#### 6. Which of the following are common security problems associated with web clients?  
A) ✓ ActiveX controls have many known security vulnerabilities.  
B) ✗ JavaScript and Java have security models but still pose risks if exploited.  
C) ✓ Downloaded files can contain viruses or trojan horses.  
D) ✓ Cookies allow sites to track user behavior, raising privacy concerns.  

**Correct:** A, C, D


#### 7. Why is it important to apply the principle of minimum privilege in user access control?  
A) ✗ Administrators require elevated privileges, unlike normal users.  
B) ✗ Giving all privileges to users increases security risks.  
C) ✓ Limiting privileges to what is necessary reduces potential misuse.  
D) ✓ Minimizing privileges reduces accidental or intentional damage.  

**Correct:** C, D


#### 8. Which of the following statements about securing servers and clients are true?  
A) ✓ Using secure OS and keeping it updated is critical for server security.  
B) ✓ Educating users is necessary as users can unintentionally compromise security.  
C) ✗ Client security is important because clients connect to networks and can be vulnerable.  
D) ✓ Disabling unneeded features reduces the attack surface on servers.  

**Correct:** A, B, D
