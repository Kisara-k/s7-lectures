## 13. Self Supervised Learning

## Key Points

#### 1. 🤖 Self-Supervised Learning (SSL) Basics
- SSL uses unlabeled data but creates labels automatically from the data itself.
- SSL combines unsupervised data (no human labels) with supervised training (prediction tasks with loss functions).
- The pretext task in SSL involves withholding part of the data and training the model to predict it.
- The main goal of SSL is to learn general-purpose representations reusable for downstream tasks.
- SSL reduces the need for expensive and slow human annotation.

#### 2. 🖼️ SSL for Images: Pretext Tasks and Methods
- Early SSL image tasks include context prediction, context encoders (inpainting), colorization, jigsaw puzzles, and rotation prediction.
- Contrastive learning trains models to bring augmented views of the same image closer and push different images apart using InfoNCE loss.
- SimCLR showed that data augmentation and a nonlinear projection head improve SSL image representations.
- Masked Image Modeling (e.g., BEiT and MAE) masks random image patches and trains models to predict missing content, inspired by BERT.
- MAE masks about 75% of patches and uses an asymmetric encoder-decoder design for efficiency.
- A ViT-Huge model pretrained with MAE achieved 87.8% accuracy on ImageNet after fine-tuning.

#### 3. 🧪 Evaluating SSL Representations
- Linear probing freezes the encoder and trains a linear classifier to test feature quality.
- k-Nearest Neighbors (k-NN) classification uses nearest training samples in feature space without additional training.
- Fine-tuning updates all model weights on labeled data to measure adaptability.
- Transfer learning applies pretrained encoders to new datasets and tasks to test generalizability.

#### 4. 📚 SSL for Text: Key Concepts and Models
- Text is suited for SSL because tokens can be masked and predicted using surrounding context.
- The distributional hypothesis states that words in similar contexts have similar meanings.
- Early word embeddings like word2vec and GloVe produce static vectors, assigning one vector per word regardless of context.
- ELMo introduced contextual embeddings using bidirectional LSTMs, giving different vectors for the same word in different sentences.
- BERT uses Masked Language Modeling (MLM), masking 15% of tokens and predicting them from both left and right context.
- BERT also uses next sentence prediction as a secondary task.
- GPT models use autoregressive training, predicting the next token from previous tokens (left-to-right).
- RoBERTa improved BERT by removing next sentence prediction, using dynamic masking, larger batches, and more data.
- XLNet uses permutation language modeling to capture bidirectional context without masking tokens.
- ELECTRA trains a discriminator to detect replaced tokens generated by a small generator, improving training efficiency.

#### 5. 🔄 Text-to-Text SSL Models
- T5 uses a sequence-to-sequence Transformer trained with span corruption, replacing random spans with sentinel tokens.
- BART is a denoising autoencoder that corrupts text (masking, deletion, permutation) and trains a seq2seq model to reconstruct the original.
- BART excels at generation tasks like summarization due to its full decoder architecture.

#### 6. ⚙️ SSL Training Objectives for Text
- Causal Language Modeling (e.g., GPT) predicts the next token using only left context; suited for generation.
- Masked Language Modeling (e.g., BERT, RoBERTa) predicts masked tokens using both left and right context; suited for classification and tagging.
- Permutation Language Modeling (e.g., XLNet) predicts tokens in random order, capturing bidirectional context.
- Replaced Token Detection (e.g., ELECTRA) detects whether tokens are original or replaced; more compute-efficient.
- Denoising Sequence-to-Sequence (e.g., T5, BART) reconstructs original text from corrupted input; suited for translation, summarization, and generation.
